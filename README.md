# Leniks API

Установите зависимости через `npm install`. Для запуска задайте переменные окружения:

- `MONGO_URI` — строка подключения к MongoDB.
- `LENIKS_TOKEN_SECRET` — постоянный секрет подписи токенов. Чтобы сохранить действующие токены после перехода, используйте содержимое прежнего `.auth-secret`.
- `LENIKS_ADMIN_USERNAME` и `LENIKS_ADMIN_PASSWORD` — учётные данные администратора при первом запуске.
- `EMAIL_USER` и `EMAIL_PASS` — учётные данные почты для кодов подтверждения.

Затем выполните `npm start`. Сервер начинает принимать запросы после подключения к MongoDB и создания индексов.

Для переноса существующих аккаунтов сначала задайте `MONGO_URI`, затем выполните `npm run import:users -- users.json` **до первого запуска сервера**. Скрипт сохраняет прежние шестизначные ID, хеши паролей, роли, подписки и настройки 2FA. Уже импортированные ID пропускаются. Файл `users.json` и секреты не отправляются в Git.

`npm test` запускает локальные проверки. Для интеграционного теста с отдельной временной базой задайте `MONGO_TEST_URI` к тестовому экземпляру MongoDB; тест удалит созданную им базу после выполнения.
